# archive/legacy/mnemos/

Materi historis dari proyek **Mnemos** (Living Knowledge Network) yang sebelumnya
berada di `scripts/` dengan nama file seperti `Claude 1`, `Claude code ui`, dan
sejenisnya.

## Mengapa ada di sini?

File-file ini **bukan bagian dari PusingCuk** dan tidak direferensikan oleh kode,
tes, workflow, maupun Makefile PusingCuk. File tersebut tampaknya tersalin ke
direktori `scripts/` secara tidak sengaja. Agar tidak mengaburkan isi `scripts/`
dan tetap mematuhi kebijakan arsip di `docs/REPO_STRUCTURE.md` (jangan menghapus
materi historis tanpa memastikan bukan input tes/kompatibilitas), file dipindahkan
ke sini alih-alih dihapus.
