Kenalan dulu

Serius bikin bahasa.
Santai cara memulai.

PusingCuk bukan sekadar ganti kata kunci. Ini proyek eksperimen untuk membangun bahasa, runtime, compiler, dan ekosistemnya secara terbuka.

⌘

Sintaks yang terasa dekat

Kata seperti jancuk, lah, dan hedeh memberi karakter lokal. Dokumentasi tetap berusaha jelas, konsisten, dan ramah pemula.

⇄

Eksperimen lintas target

Repo sudah memiliki jalur compiler untuk JavaScript, Python, HTML, JSON IR, dan bytecode VM. Cakupan tiap target belum identik—itulah salah satu area kontribusi.

✳

Dibangun bersama

Mulai dari perbaikan dokumentasi, contoh program, tes konformansi, isu bug, sampai desain fitur. Kamu tidak harus jadi senior untuk membantu.

Mulai dalam beberapa menit

Dari clone sampai program pertama.

Jalur berikut memakai compiler multi-target Python yang ada di repo. Fitur bahasa dan backend masih eksperimental; cek dokumentasi untuk batas dukungan terbaru.

Panduan pemula ↗Dokumentasi compiler ↗
01

Ambil kode sumber

git clone https://github.com/rllibo833-sudo/pusingcuk.git
02

Buat program

Simpan sebagai halo.pusingcuk. Ini sama dengan file contoh yang ada di repo:

jancuk

lah nama = "Dunia"
hedeh "Halo, " + nama

selesai jancuk
03

Kompilasi ke JavaScript

python -m compiler halo.pusingcuk --target js --output halo.js

Jalankan hasilnya dengan Node.js: node halo.js.

04

Jelajahi target lain

Untuk target lain, gunakan opsi yang sama: --target python, --target html, --target json, atau --target vm.

Kami ingin bahasa ini tumbuh dari bukti, tes, dan kontribusi—bukan klaim fitur yang belum berjalan.

Compiler multi-target

Sudah ada target awal JS, Python, HTML, JSON IR, dan VM. Kesetaraan fitur masih perlu diperluas.

Konformansi dan semantik

Tambah tes lintas runtime, spesifikasi perilaku, pesan error, serta validasi input.

Pengalaman developer

Contoh, formatter, tooling editor, diagnostik, dan tutorial yang mudah diikuti.

Integrasi ekosistem

Web API, database, server, WebAssembly, dan FFI adalah arah eksplorasi—belum dianggap tersedia penuh.
