01 / The language

A language with its own voice.

The .cuk identity uses Indonesian keywords and everyday expressions as real language constructs—not just translated labels. The project explores approachable syntax while keeping specifications, diagnostics, and implementation limits explicit.

Readable by design. Honest about its limits.

Start with small programs, learn the syntax, and inspect what each compiler or runtime actually supports. The reference interpreter is not the same thing as a fully independent native runtime.

02 / The ecosystem

Three connected ideas. Clear responsibilities.

The language is the foundation. The AI concept can help people work with it, while the Reality Engine demonstrates inspectable rule-based behavior. Their maturity and capabilities are not overstated.
