Runtime browser

Runtime membaca sintaks .cuk dan mengeksekusi AST yang dibatasi. Kode pengguna tidak dievaluasi sebagai JavaScript.

Batas eksekusi

  • Maksimal 64 KB kode sumber.
  • Maksimal 50.000 langkah runtime.
  • Maksimal 10.000 item per koleksi atau iterasi.
  • Output maksimal 64 KB.
  • Input interaktif, filesystem, dan jaringan tidak tersedia.

Runtime browser adalah target tersendiri; sintaks atau fitur yang belum didukung menghasilkan diagnostik.
