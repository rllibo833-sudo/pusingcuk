Tulis .cuk. Jalankan interpreter referensi.

Editor browser untuk mencoba contoh .cuk yang disimpan di repositori. Galeri dibuat otomatis dari berkas contoh dan contoh-contohnya diperiksa terhadap interpreter referensi dalam CI.

Catatan mesin sementara Python: playground ini memuat modul interpreter referensi Python dari repositori ke Pyodide 0.27.7. Ini bukan runtime native mandiri. Koneksi internet diperlukan untuk memuat Pyodide dan modul situs. Kode tidak dikirim ke server. Operasi file, jaringan, JSON, dan input interaktif diblokir untuk sesi playground.
